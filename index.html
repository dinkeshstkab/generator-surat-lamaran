Cara Deploy ke GitHub Pages

Ikuti langkah mudah berikut untuk mempublikasikan website ini secara gratis di internet menggunakan GitHub Pages:

  1. Buat Repositori Baru:

    Buka github.com/new, beri nama repository (misal: surat-lamaran), lalu pilih Public dan klik Create repository.

  2. Upload File HTML:

    Simpan kode halaman web ini sebagai file bernama index.html di komputer Anda. Di GitHub, klik link "uploading an existing file" lalu drag file index.html tersebut.

  3. Commit Changes:

    Klik tombol hijau Commit changes di bagian bawah halaman GitHub.

  4. Aktifkan GitHub Pages:

    Masuk ke tab Settings → menu Pages di sebelah kiri. Pada bagian Branch, ubah dari None menjadi main (atau master), lalu klik Save.

Selesai! Dalam 1-2 menit, website Anda sudah aktif dan dapat diakses publik melalui link unik GitHub Pages Anda!
